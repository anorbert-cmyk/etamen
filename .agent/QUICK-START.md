# Agentic Kit Quick Start

## 🚀 Command Cheat Sheet

```bash
# New product (6-phase, fully automated)
/fullstack-idea "Your idea description"

# Quick MVP (1 hour prototype)
/fullstack-idea --quick "Your idea"

# Check if idea is feasible
/ralph-idea "Your idea"

# Run existing tasks
/ralph

# Add feature to existing app
/enhance "Feature description"

# Fix bug with analysis
/debug "Problem description"

# Plan big changes
/orchestrate "Change description"

# Brainstorm options
/brainstorm "Question or topic"

# Run tests
/test

# Deploy to production
/deploy

# Optimize content for SEO
/content-loop path/to/file.md "target keyword"

# Show project status
/status
```

---

## 📋 Decision Matrix: Which Command?

### Building Something New?
- **Full product** → `/fullstack-idea`
- **Quick prototype** → `/fullstack-idea --quick`
- **Need validation first** → `/ralph-idea`

### Working on Existing Project?
- **Adding feature** → `/enhance`
- **Fixing bug** → `/debug`
- **Big refactor** → `/orchestrate`
- **Run tests** → `/test`
- **Ship to prod** → `/deploy`

### Need Guidance?
- **Brainstorm ideas** → `/brainstorm`
- **Plan something** → `/plan`
- **Improve content** → `/content-loop`
- **Check status** → `/status`
