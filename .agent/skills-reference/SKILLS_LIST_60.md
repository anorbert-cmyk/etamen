## Miert ezeket valasztottam?

A 60 skill-t **7 fo kategoriaba** szerveztem, az alabbi szempontok alapjan:

1. **Napi hasznalhatosag** - Olyan skillek, amiket nap mint nap hasznal egy fejleszto/marketer/designer
2. **Idomegtakaritas** - Automatizaljak az ismetlodo feladatokat
3. **Minosegbiztositas** - Segitenek a hibak elkeruleset es a kod minoseg fenntartasat
4. **Biztonsag** - Vedik a kodot es az infrastrukturat
5. **Skalazhatosag** - A ValidateStrategyLive projekthez is relevansak (React, TypeScript, Node.js, tRPC)
6. **Kozossegi validacio** - Min. 2+ GitHub star, aktivan karbantartott
7. **Kombinalhatok** - A skillek egyutt is mukodnek (pl. code-reviewer + git-automation)
